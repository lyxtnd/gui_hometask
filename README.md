# GUI — домашнее задание по информатике

Репозиторий с двумя десктопными приложениями на Python и PySide6 (Qt for Python):

1. **Patients** — таблица пациентов с расчётом ИМТ, добавлением и редактированием записей и окном статистики с графиками.
2. **Calculator** — калькулятор с поддержкой клавиатуры, степени и квадратного корня.

## Возможности

### Patients
- Таблица пациентов: ФИО, возраст, пол, рост, вес и автоматически рассчитанный ИМТ.
- Добавление нового пациента и редактирование выбранного через диалоговое окно.
- Данные хранятся в JSON-файле. Если данных ещё нет, при первом запуске автоматически генерируются 30 тестовых пациентов (библиотека Faker).
- Окно «Статистика пациентов» с четырьмя вкладками (matplotlib): распределение по полу, распределение по возрасту, ИМТ по полу, зависимость ИМТ от возраста.
- Адаптивный интерфейс: шрифты, кнопки и ширина столбцов масштабируются вместе с окном.

### Calculator
- Операции: `+`, `−`, `×`, `÷`, возведение в степень (`xʸ`), квадратный корень (`√`).
- Кнопки `Clr` (очистить всё) и `Del` (удалить последний символ).
- Ввод с клавиатуры: цифры и операторы, `Enter` или `=` — результат, `Backspace` — удалить символ, `Esc` — очистка.
- Обработка ошибок: деление на ноль, неверный синтаксис, комплексный результат.

## Требования

- **Python 3.10 или новее**
- **Git**
- Библиотеки (ставятся в виртуальное окружение, см. ниже): `PySide6`, `matplotlib` (версии 3.9 или новее), `faker`

## Установка

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/lyxtnd/gui_hometask
cd gui_hometask
```

### 2. Создайте виртуальное окружение

**Виртуальное окружение** — это отдельная изолированная папка с собственной копией Python и своими библиотеками. Благодаря ей библиотеки этого проекта не смешиваются с остальными проектами и системным Python, ничего не конфликтует, а удалить всё одной командой (удалением папки) можно в любой момент.

Окружение называется `gui-homework-env` и создаётся прямо в папке `GUI`, поэтому все установленные библиотеки лежат внутри неё и больше нигде на компьютере не появляются.

**Windows (PowerShell или cmd):**

```bash
python -m venv gui-homework-env
gui-homework-env\Scripts\activate
```

> Если PowerShell ругается на запрет выполнения скриптов, выполните в этом же окне `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` и повторите активацию. Настройка действует только до закрытия окна.

**macOS:**

```bash
python3 -m venv gui-homework-env
source gui-homework-env/bin/activate
```

**Linux:**

```bash
python3 -m venv gui-homework-env
source gui-homework-env/bin/activate
```

> На Ubuntu/Debian модуль `venv` может быть не установлен. Тогда сначала выполните `sudo apt install python3-venv`.

После активации в начале строки терминала появится `(gui-homework-env)`. Это значит, что всё, что вы теперь установите через `pip`, попадёт только в это окружение.

### 3. Установите библиотеки в окружение

Убедитесь, что окружение активно (в строке есть `(gui-homework-env)`), и выполните:

```bash
pip install PySide6 "matplotlib>=3.9" faker
```

### 4. Проверьте установку

```bash
python -c "import PySide6, matplotlib, faker; print('Всё установлено')"
```

Если вывелась фраза «Всё установлено», можно запускать.

## Запуск

Каждое приложение запускается **из собственной папки**: иконки и импорты используют относительные пути. Перед запуском окружение должно быть активно (шаг 2).

### Patients

```bash
cd patients
python main.py
```

### Calculator

```bash
cd calculator
python calculator.py
```

### Выход из окружения

Когда закончили работу:

```bash
deactivate
```

В следующий раз окружение создавать заново не нужно — достаточно снова выполнить команду активации из шага 2 и запустить программу.

## Где что сохраняется

- **Библиотеки** — только внутри папки `GUI/gui-homework-env/`. Чтобы полностью убрать их с компьютера, достаточно удалить эту папку.
- **Данные пациентов** — в JSON-файле, путь к которому задан в `manager.py`. Файл обновляется после каждого добавления или изменения пациента. Чтобы сбросить данные и заново сгенерировать 30 тестовых пациентов, удалите этот файл и перезапустите приложение.

Папку `gui-homework-env/` не нужно добавлять в репозиторий: добавьте её в `.gitignore`.

```
gui-homework-env/
__pycache__/
```

## Возможные проблемы

| Проблема | Решение |
|---|---|
| `ModuleNotFoundError: No module named 'PySide6'` (или `matplotlib`, `faker`) | Не активировано окружение или не выполнен шаг 3. Активируйте `gui-homework-env` и повторите установку. |
| `ModuleNotFoundError: No module named 'generated'` / `'manager'` / `'data'` | Приложение запущено не из своей папки. Перейдите в `Patients` и запустите заново. |
| `TypeError: boxplot() got an unexpected keyword argument 'tick_labels'` | Старая версия matplotlib. Обновите: `pip install -U "matplotlib>=3.9"`. |
| Не отображаются иконки на кнопках | Проверьте, что папка `icons` лежит в `Patients` и запуск идёт из этой папки. |
| `could not load the Qt platform plugin "xcb"` (Linux) | Установите библиотеки: `sudo apt install libxcb-cursor0 libxkbcommon-x11-0`. |
| Шрифт выглядит иначе | Установите Futura / Segoe UI или замените название шрифта в коде. |
